# Группы устройств и общие команды

Группа объединяет устройства для просмотра и общего управления, например
«Кухня» или «Мастерская». Сейчас одно устройство относится к одной группе
либо остаётся без группы. Группы и назначения команд хранятся в SQLite
Gateway и доступны всем браузерам этой установки.

## Создание и изменение группы

1. На странице «Устройства» откройте управление группами и создайте группу.
   Название — от 1 до 60 символов; одинаковые названия не допускаются.
2. В карточке устройства нажмите шестерёнку между звездой и поиском устройства
   и выберите группу в окне настроек. «Без группы» снимает
   назначение. Устройство при этом не отключается и не перепрошивается.
3. Выберите группу в фильтре страницы для просмотра её устройств.

Название группы также видно рядом с именем и статусом на карточке устройства.
Для устройства без назначения показывается «Без группы».
Вверху окна шестерёнки редактируются имя и ID; ID можно менять при отключённом
устройстве. На широком экране выбор группы и общее выключение находятся рядом,
на узком — друг под другом.

Группу можно переименовать и удалить. Удаление группы оставляет устройства,
их настройки и сценарии, снимая только объединение. Можно создать до 100
групп. Переименование ID устройства переносит членство и назначения вместе
с остальными его данными.

## Что означает общее «Выключить»

Gateway не угадывает смысл выключения по названию параметра. Каждое устройство
явно объявляет или получает от пользователя операцию общей команды `off`.

| Устройство | Назначение `off` |
| --- | --- |
| Лампа / реле розетки | Установить boolean-параметр `enabled = false` |
| Вентилятор с диапазоном скорости | Установить параметр `speed = 0` |
| Сложный режим остановки | Вызвать объявленное действие `stop` с аргументами |
| Нет подходящей операции | Не участвовать |

Нулевое значение должно быть разрешено Schema. Если диапазон скорости
начинается с 1, назначение `speed = 0` будет отклонено. Выберите другое
предусмотренное прошивкой действие или расширьте саму прошивку.

В окне шестерёнки находится раздел «Общее выключение». Доступны:

- **По прошивке** — использовать `schema.common_commands.off`, если он объявлен.
- **Не участвует** — отключить участие, даже если прошивка задаёт назначение.
- **Установить параметр** — выбрать `read_write` и допустимое значение.
- **Вызвать действие** — выбрать действие и заполнить его аргументы.

Пользовательское назначение имеет приоритет и сохраняется отдельно, без
изменения Schema. «По прошивке» удаляет пользовательское переопределение.
После изменения Schema назначение повторно проверяется при выполнении:
устаревший ID не превращается в другую операцию.

В этом же окне находится история Schema: выбор снимка, восстановление для
Gateway, скачивание текущей Schema и удаление снимка из истории. Для
восстановления устройство должно быть отключено; это не перепрошивка ESP32.

## Выполнение для всех или группы

«Выключить все» относится ко всем известным устройствам независимо от поиска
и фильтров страницы. Кнопка группы относится только к выбранной группе.
Перед отправкой показываются область действия и количество назначений.

Gateway использует обычные команды и проверяет ACK каждого устройства.
Результаты: выполнено, ошибка или пропуск. Отключённые устройства,
нерассмотренная Schema, неприменённая конфигурация и отсутствие назначения
приводят к пропуску. Занятая операция может завершиться отказом;
успех показывается только после подтверждения.

Групповые команды не остаются в очереди на следующее подключение или
перезапуск Gateway. При потере ACK результат может быть неизвестен: перед
повтором проверьте фактическое состояние. Изменение параметра может запускать
включённые сценарии по его изменению.

`off` описывает поведение устройства, а не гарантированное отключение питания
самой ESP32. Сон, остановку двигателя и выключение выхода реализует прошивка.
Для сложной остановки объявите одно действие с нужным алгоритмом на плате.

## Назначение по умолчанию в Schema

```json
{
  "format_version": 1,
  "parameters": {
    "speed": {
      "label": "Скорость вентилятора",
      "type": "integer",
      "access": "read_write",
      "min": 0,
      "max": 100,
      "step": 1,
      "control": "slider",
      "unit": "%"
    }
  },
  "actions": {},
  "common_commands": {
    "off": {"kind": "parameter", "name": "speed", "value": 0}
  }
}
```

Для действия назначение имеет вид
`{"kind": "action", "name": "stop", "arguments": {}}`; действие должно
существовать в `schema.actions`, а аргументы — соответствовать описанию.
Сейчас общая команда только одна — `off`. LED-пример объявляет её явно как
`led = false`; универсальная прошивка ожидает пользовательского назначения.

Для последовательности действий создайте отдельный серверный сценарий с
событием «По нажатию кнопки» и включите показ кнопки на странице устройств.
Это удобно для «Ночного режима» или «Ушёл из дома»; назначение общего `off`
по-прежнему задаёт одну операцию каждого устройства.
[Инструкция ручного запуска](AUTOMATION.md#запуск-сценария-кнопкой).
Группы и пользовательские назначения входят в полную
[резервную копию Gateway](../gateway/README.md#данные-и-резервные-копии),
но не в JSON-экспорт аппаратной конфигурации.
